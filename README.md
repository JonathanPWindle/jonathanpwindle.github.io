# jwindle.uk

Personal site of Dr Jonathan Windle, served by GitHub Pages at https://jwindle.uk.

Plain static HTML and CSS, no build step.

- `index.html` – homepage (research, path, recently)
- `publication/<slug>/index.html` – one page per paper
- `assets/site.css` – all styles
- `images/`, `files/` – images and PDFs
- `CNAME` – custom domain

To add a paper: add an entry to the relevant theme list and the "Recently" feed in `index.html`, then copy an existing `publication/<slug>/` page and edit it.
